# Keyboard shortcuts and slash commands

NoteTrace works well from the keyboard. Press **?** anywhere in the notes list to see every shortcut, or open **Settings, Appearance, Keyboard Shortcuts, View**.

Single-key shortcuts only work when you're not typing in a field. Turn them off on a device with the switch in **Settings, Appearance, Keyboard Shortcuts** (the `?` sheet and Ctrl+K still work).

## Notes list

| Keys | Does |
|---|---|
| `c` | New note |
| `l` | New list |
| `v` | New voice note (starts recording) |
| `/` | Search (opens the search box in the header) |
| `Ctrl` + `K` (`⌘` + `K` on a Mac) | Search, from anywhere in the app |
| `j` / `k` | Next / previous note |
| `Enter` | Open the note |
| `x` | Select the note |
| `f` | Pin or unpin (the focused note, or every selected note) |
| `e` | Archive (in Archive, unarchive) |
| `#` | Move to trash |
| `Ctrl` + `A` | Select all notes in view |
| `Esc` | Clear the selection |
| `↑` / `↓` | In the List layout's two-pane view, open the previous / next note |
| `?` | Show all shortcuts |

## Drawing {#drawing}

| Keys | Does |
|---|---|
| `p` / `m` / `h` | Pen / marker / highlighter |
| `e` | Eraser |
| `s` | Select (lasso) |
| `Ctrl` + `Z` | Undo |
| `Ctrl` + `Shift` + `Z` or `Ctrl` + `Y` | Redo |
| `Delete` | Delete the selected strokes |
| `Space` + drag | Pan |
| `Ctrl` + wheel | Zoom |
| `0` | Fit the sheet to the width |
| `Esc` | Clear the selection, or save and close |

## Tasks {#tasks}

| Keys | Does |
|---|---|
| `n` or `c` | Add a task |
| `j` / `k` | Next / previous task |
| `x` or `Space` | Tick the task (a repeating one moves to its next date) |
| `e` or `Enter` | Edit the task |
| `d` | Due date and repeat |
| `m` | Move to another list |
| `o` | Open its list |
| `#` or `Delete` | Delete the task (with Undo) |

## Go to

Press `g`, then:

| Keys | Goes to |
|---|---|
| `g` then `n` | Notes |
| `g` then `r` | Reminders |
| `g` then `a` | Archive |
| `g` then `t` | Trash |
| `g` then `s` | Settings |

## In a note

| Keys | Does |
|---|---|
| `Ctrl` + `Enter` | Done (save and close) |
| `Esc` | Close the note |
| `[[` | Link to another note |
| `/` | Slash commands (below) |

## Slash commands

In a text note, type `/` at the start of a line or after a space. A menu of commands opens; keep typing to filter it, use the arrow keys, and press `Enter`. `Esc` closes the menu without closing the note.

| Command | Does |
|---|---|
| Checklist | Turns the note into a checklist |
| Large Heading, Heading, Small Heading | Makes the line a heading |
| Bulleted List, Numbered List | Starts a list |
| Quote | Makes a quote |
| Code Block | Starts a code block |
| Divider | Adds a horizontal line |
| Link to a Note | Starts a `[[link]]` |
| Today's Date, Current Time | Inserts the date or time |
| Image | Opens the image picker |
| Voice Note | Starts recording |
| Reminder | Opens the reminder picker |

Checklist, Image, Voice Note, and Reminder only show where they apply: not on a note shared with you as view-only, and Reminder only on your own notes.
